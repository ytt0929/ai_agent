# OpenClaw Prompt: 智能报告改造成 AI 报告交付工作台

请修改 `D:\demo\ai-copilot` 项目中的“智能报告”功能。

本次不要把智能报告做成传统 SaaS 报告管理页，也不要做成企业分析/问数工具。智能报告的新定位是：

```text
AI 报告交付工作台
```

一句话目标：

```text
把模板、资料包、尽调产物和报告正文组织成可修改、可追溯、可导出的正式报告。
```

## 1. OpenClaw 本次角色定位

你需要同时扮演：

### 1.1 资深 AI 产品经理

- 目标是把“智能报告”从普通报告列表页，改成 AI 报告交付工作台。
- 用户进入页面后，应明确感受到：可以直接让 AI 生成报告、修改正文、补资料、按新模板重排、打包导出。
- 不要把首页做成“指标卡 + 模板卡 + 最近报告”的传统 SaaS 看板。
- AI 能力必须围绕“报告交付”，不要做企业经营问数、指标计算、异常探查、风险评分解释。

### 1.2 资深银行业务产品经理

- 智能报告面向银行客户经理，核心任务是生成和交付正式报告。
- 报告不是普通摘要，而是和模板、资料、章节、附件、尽调结论强关联的交付物。
- 重点体现：模板版本、章节资料包、待确认内容、资料缺失、正文改写、附件导出。

### 1.3 资深前端工程师

- 当前 `SmartReportPage.vue` 和 `mockSmartReport.js` 可能存在乱码、半截字符串、注释吞掉 `const/export` 的问题。
- 不要局部修补乱码，请直接用 UTF-8 正常中文重写允许修改的文件。
- 使用 Vue3 + Element Plus，不新增 UI 库。
- 保证 `npm run build` 通过。

## 2. 模块边界

### 2.1 智能报告负责

智能报告负责：

- 维护报告模板
- 上传报告模板
- 识别模板章节
- 配置章节资料要求
- 管理客户资料包
- 管理章节关联资料
- 从智能尽调产物生成报告
- 从资料附件生成报告
- 按新模板重新生成报告
- 修改待确认内容
- 使用 AI 快速修改文字表述
- 查看每个章节关联资料包详情
- 修改资料包内容
- 上传补充资料
- 将报告和资料包批量导出

### 2.2 智能报告不负责

以下能力不要放在智能报告里：

- 问企业经营数据
- 计算经营指标
- 查找经营异常
- 解释风险评分
- 追问异常原因
- 做完整尽调核验

这些能力属于【企业探查】或【智能尽调】。

### 2.3 和其他模块关系

```text
企业探查：数据到洞察
智能尽调：资料到尽调结论
智能报告：资料到报告，报告到交付
```

智能报告可以接受资料，但不替代尽调结论。

智能报告可以提示缺资料，但不完成尽调核验。

智能报告发现需要核验时，可以展示“发起尽调核验”按钮，但本次只做 UI message，不改智能尽调逻辑。

## 8. 生成态设计

生成态要体现 AI 把资料组织成报告，而不是普通 spinner。
