# OpenClaw 提示词：智能报告模块改造

请修改 `D:\demo\ai-copilot` 项目中的“智能报告”功能。

## 重要边界

本次只改智能报告模块，不要改智能尽调的数据结构和入口逻辑。

允许修改：

- `src/pages/SmartReportPage.vue`
- `src/data/mockSmartReport.js`
- 如确有必要，可新增 `src/components/report/` 下的智能报告组件

不要修改：

- `src/pages/DueDiligenceTaskPage.vue`
- `src/stores/dueDiligence.js`
- `src/data/mockDueDiligence.js`
- `src/stores/workbenchAssistant.js`
- 路由结构
- 侧边栏结构

## 当前代码状态

- `SmartReportPage.vue` 目前仍然 `import useDueDiligenceStore`、`mockEnterpriseDiagnosis`、`getDiagnosisMock`，并从尽调任务和企业诊断数据推导报告列表。
- 这次需要去掉这些依赖，让智能报告只使用 `src/data/mockSmartReport.js` 里的 mock 数据。
- `mockSmartReport.js` 中如有乱码或半截字符串，请直接整理为 UTF-8 正常中文 mock 数据。
- 页面不要再依赖 route query 自动打开尽调产物。

## 产品定位

智能报告不是智能尽调流程本身，而是：

> 报告模板库 + 报告生成器 + 报告编辑器 + 证据追问工具

目标是把 `/smart-report` 做成银行客户经理编制授信调查报告的专业报告工作台，不接真实后端，只用 mock 数据模拟。

## 四、报告编辑工作台

采用三栏布局：

```text
左侧：报告目录
中间：报告正文
右侧：AI 报告助手
```

顶部上下文栏展示：

- 企业名称
- 报告类型
- 来源
- 版本
- 状态
- 证据数
- 风险数
- 待确认数

右侧操作按钮：

- 保存草稿
- 导出 Word
- 提交确认
- 返回工作台

按钮反馈：

- 保存草稿：message 成功
- 导出 Word：message 成功
- 提交确认：如果还有待确认项，message warning 阻止提交；全部确认后 message success

左侧报告目录：

- 显示 15 个章节。
- 每个章节显示编号、标题、状态标签。
- 点击章节后，中间滚动或切换到对应章节。
- 状态标签要有不同颜色。

中间报告正文：

样式要像正式银行报告文档：

- 白色纸张
- 清晰章节编号
- 正文段落
- 表格
- 证据来源
- 缺失证据提示
- 待确认提示
- 风险条目

每个章节支持局部编辑：

- 点击“修改”进入 textarea
- 保存后更新该章节 body
- 取消恢复展示

右侧 AI 报告助手：

- 标题：AI 报告助手
- 副标题：可追问数据、改写章节、检查规则

包含：

1. 规则检查卡
   - 缺失证据 3
   - 待确认结论 3
   - 禁用词 0
   - 模板规则 2

2. 待确认事项
   - 税票授权缺口说明
   - 法人关联企业说明
   - 偿债能力结论

每项有“确认”按钮。确认后状态变成已确认。提交确认必须等这些都确认。

3. 快捷操作按钮
   - 展开风险分析
   - 补充税票数据
   - 改成审批口吻
   - 检查缺失证据
   - 生成授信方案
   - 检查禁用词

4. 对话输入框

placeholder：

```text
询问数据来源，或告诉我如何修改当前报告...
```

Mock 回复：

- 展开风险分析：输出高/中/低风险，并说明证据来源
- 补充税票数据：说明已补充税票章节，同时提示 2024 税票缺失
- 改成审批口吻：输出更正式的银行审批语气
- 检查缺失证据：列出银行流水、2024 税票授权、实控人关联企业说明
- 生成授信方案：输出金额、期限、担保、提款条件、贷后管理
- 检查禁用词：提示未发现“建议同意 / 拟同意 / 妥否请审批”等禁用词

## 五、UI 风格要求

- 专业、克制、银行后台系统风格
- 不要做营销页
- 不要做大 hero
- 不要大面积紫色渐变
- 不要卡片套卡片
- 报告正文要像正式文档
- 左侧目录宽度 220-260px
- 右侧助手宽度 340-380px
- 中间正文自适应
- 1440px 宽度下不能重叠
- 小屏幕可以改为纵向堆叠
- 所有中文必须正常显示，不要乱码

## 六、验收标准

完成后请运行：

```bash
npm run build
```

必须满足：

- build 通过
- `/smart-report` 默认显示智能报告工作台
- 点击继续编辑能进入三栏编辑工作台
- 左侧目录可切换章节
- 正文可编辑并保存
- AI 快捷按钮有 mock 回复
- 保存、导出、提交有 UI 反馈
- 提交在待确认事项未处理时会阻止
- 不修改智能尽调相关文件、路由、侧边栏
