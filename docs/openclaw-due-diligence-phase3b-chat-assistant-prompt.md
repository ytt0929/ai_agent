## 5. 消息模型

请使用任务级消息，不要每次切阶段就丢失对话。

建议在 store 中新增或调整：

```js
function getTaskChatMessages(taskId) {}
function addTaskChatMessage(taskId, message) {}
function clearTaskChatMessages(taskId) {}
```

消息对象建议：

```js
{
  id: string,
  role: 'ai' | 'user',
  text: string,
  time: '15:40',
  stage: 'tax-rpa',
}
```

如果不想大改 store，也可以在 `DueDiligenceTaskPage.vue` 内用 `computed` + `store.chatMessages` 实现，但必须保证：

- 同一任务下消息连续显示
- 切换阶段不清空
- 刷新后可用 mock 初始消息恢复也可以

## 8. 输入框自然语言推进

右侧底部必须有输入框和发送按钮。

输入后追加用户消息，并根据关键词模拟推进：

```text
包含“提醒”              → 等同发送提醒
包含“授权”              → 等同模拟企业已授权
包含“上传”或“补齐”       → 等同模拟客户上传资料
包含“证据”              → 查看证据详情或进入证据整合
包含“风险”              → 进入风险诊断
包含“产物”或“报告”       → 生成产物或查看报告
包含“导出”              → 导出报告
包含“稍后”或“保存”       → 稍后继续
```

如果无法识别：

```text
AI：我已收到你的问题。你也可以点击下方快捷动作继续推进当前尽调任务。
```

## 9. UI 要求

必须使用 Element Plus 和项目 token。

推荐组件：

- `el-card`
- `el-button`
- `el-tag`
- `el-input`
- `el-scrollbar`
- `el-empty`
- `el-divider`

视觉要求：

- 右侧面板参考工作台 AI Copilot 的对话面板，不要像普通后台操作卡。
- AI 消息左侧，用户消息右侧。
- AI 消息浅灰或浅蓝背景，用户消息使用主色背景。
- 快捷动作使用轻量按钮或 tag，不要堆满大按钮。
- 输入框固定在右侧面板底部。
- 消息区可滚动，不要挤压左侧工作区。
- 样式使用 `src/styles/token.css` 变量：

## 10. 左侧产物本轮只做必要联动

本轮主要目标是右侧对话式助手。

左侧只需要确保：

- 点击「模拟企业已授权」后，税票状态能变成已采集，或阶段切到资料补充
- 点击「模拟客户上传资料」后，资料完整度能体现 86%，或阶段切到证据整合
- 点击「进入风险诊断」后，阶段切到风险诊断
- 点击「生成产物」后，阶段切到产物确认
- 点击「查看报告」后，能打开产物确认里的报告预览

不要在本轮大规模重写左侧 artifact。

本轮左侧验收标准是“能跟随右侧对话推进发生阶段变化”，不是“每个阶段产物都最终丰富化”。左侧内容丰富化留到下一轮：

```text
Phase 3-B-2：左侧阶段产物丰富化
```
