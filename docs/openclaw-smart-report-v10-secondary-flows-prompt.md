## 本轮产品目标

智能报告应该有 3 个清楚的二级交互：

1. 报告中心
   - 查看所有报告
   - 新增报告
   - 查看报告详情
   - 继续修改报告
   - 查看缺失材料
   - 按模板生成报告

2. 模板中心
   - 维护模板
   - 查看模板章节规则
   - 查看模板需要哪些材料
   - 上传新版模板

3. 按模板生成报告流程
   - 必须先进入 AI 对话/任务确认面板
   - AI 识别企业、来源报告、来源材料包、目标模板
   - AI 展示目标模板需要哪些材料
   - AI 标出已有材料和缺失材料
   - 用户确认后创建生成任务
   - 生成后进入报告详情页或生成结果页

## 五、修复 openReport mode

当前很多地方调用：

```js
openReport(row, 'continue-edit')
openReport(row, 'view-missing')
openReport(row, 'regen-template')
```

但函数定义是：

```js
function openReport(task) {}
```

请改为：

```js
function openReport(task, mode = 'view-detail') {}
```

并根据 mode 设置：

- `continue-edit`
  - 默认定位第一个待确认或资料不足章节
  - AI 面板提示继续修改
- `view-missing`
  - 默认定位第一个资料不足章节
  - AI 面板提示缺失材料
- `regen-template`
  - AI 面板提示按模板生成任务
- `view-detail`
  - 正常打开报告详情

不要破坏现有详情页。
