# 工作台与智能尽调融合方案讨论稿

## 1. 基本定位

工作台不是简单跳转到智能尽调页面，而是智能尽调的一个 AI 发起入口。

建议统一为：

```text
工作台 = AI 发起入口 + 跨工具编排入口
智能尽调 = 尽调任务详情入口 + 深度处理入口

两者共用同一套“尽调任务工作区”：
DueTaskHeader + DueFlowProgress + DueStageResultPanel
```

工作台前半段保留筛客、企业探查、监控、新建尽调等工具编排感；用户确认新建尽调后，左侧切换成智能尽调任务工作区，右侧继续保留 AI Copilot 对话。

## 5. 交互原则

```text
右侧对话 = 事件入口
左侧工作区 = 状态结果展示
顶部流程条 = 全局进度导航
```

右侧 AI 不承载大结果，只负责解释、确认、推进和快捷动作。

## 6. 节点左侧展示总览

```text
工商核验   → 企业基础信息 + 主体状态 + 司法风险 + 关联企业
司法查询   → 诉讼/执行/处罚/裁判文书结果
税票采集   → 授权状态 + 采集进度 + 发票/申报结果 + 日志
资料补充   → 资料包完整度 + 已收集 + 缺失资料 + 识别字段
证据整合   → 工商证据 + 税票证据 + 资料证据 + 风险关联证据
风险诊断   → 风险评分 + 风险事项 + 诊断结论 + 建议措施
产物确认   → 报告草稿 + 资料包 + 附件清单 + 待确认项
```

## 9. 节点交互话术与流程推进

右侧 AI Copilot 的话术分成三类：状态说明、用户确认、推进下一步。每个节点都不要让 AI 一次性输出太多内容，而是像流程主持人一样，一步一步把用户带到下一个节点。

整体推进链路：

```text
智能筛客
  ↓ 选择企业 / 用户确认探查
企业探查
  ↓ 用户选择：加入监控 / 新建尽调
新建尽调
  ↓ 用户选择模板
工商核验
  ↓ 自动完成后进入司法查询
司法查询
  ↓ 自动完成后进入税票采集
税票采集
  ↓ 用户确认发送授权链接 / 模拟企业授权
资料补充
  ↓ 用户确认模拟上传 / 标记资料满足
证据整合
  ↓ AI 自动整合完成
风险诊断
  ↓ 用户查看诊断 / 确认同步报告
产物确认
  ↓ 用户点击编辑报告
报告编辑模式
  ↓ 用户确认 / 修改 / 导出
完成
```

### 10.1 产物名称与报告底稿关系

```text

- 尽职调查报告

- 税票分析报告
```

其中：


## 11. Phase 3：智能尽调任务台账与工作台同步规划

工作台发起的尽调不能表现为一次性自动跑完的脚本，而应该沉淀为一个可持续推进的尽调任务。

三类页面的定位如下：


### 11.8 工作台与智能尽调的同步边界和话术

产品决策：工作台是智能尽调的 AI 发起入口，智能尽调是长流程任务主工作区。主路径只做「工作台 → 智能尽调」的单向承接，不再把「智能尽调 → 工作台」作为主路径实现。

因此：
- 工作台可以创建尽调任务，并同步到智能尽调任务台账。
- 工作台创建任务后，不直接跳转智能尽调详情页，不提供「进入智能尽调任务」按钮。
- 工作台创建任务后，仅在右侧 AI Copilot 上下文建议区提供「稍后处理」动作。
- 用户不点击「稍后处理」时，工作台应继续完整 demo 流程，仍可在当前对话中推进工商核验、司法查询、税票采集、资料补充、证据整合、风险诊断、产物确认。
- 用户点击「稍后处理」时，页面不跳转，只提示用户稍后点击左侧菜单「智能尽调」，进入任务台账继续处理。
- 用户点击左侧菜单「智能尽调」时，进入 `/due-diligence` 任务台账；在台账中点击「继续处理」后，才进入 `/due-diligence/:taskId` 详情页。
- 用户点击左侧菜单「工作台」时，应回到工作台首页，而不是停留在工作台二级对话页。
- 智能尽调详情页保留自身完整处理能力，用户在这里完成税票授权、资料补充、证据整合、风险诊断、产物确认。
- 智能尽调页面不需要强调回到工作台继续推进；如保留返回按钮，也只是普通导航，不作为流程主动作。
- Phase 3-C 不做双向同步、不做工作台恢复任务、不做智能尽调推进后反写工作台对话。

工作台右侧 AI：

```text
我已为你创建尽调任务，已同步到智能尽调。
你可以继续在工作台完成当前流程；如果稍后再处理，可以在智能尽调任务台账中继续。
```

工作台动作：

```text
[稍后处理]
```

用户不点「稍后处理」时：

```text
工作台继续推进完整流程：
工商核验 → 司法查询 → 税票采集 → 资料补充 → 证据整合 → 风险诊断 → 产物确认
```

用户点击「稍后处理」时：

```text
已为你保留该尽调任务。稍后请点击左侧菜单「智能尽调」，在任务台账中继续处理。
```

智能尽调任务详情：

```text
该任务由工作台 AI 创建，当前状态已同步。
请在当前智能尽调任务页继续处理税票授权、资料补充、证据整合和报告确认。
```

等待外部动作时：

```text
当前任务已保留在「税票采集 · 等待企业授权」状态。
你可以稍后回到智能尽调任务台账，从该任务继续处理。
```

### 11.9 Phase 3 实施拆分

不要一次性把智能尽调、工作台、智能报告全部打通。建议拆分：

```text
Phase 3-A：智能尽调首页台账
- 新建尽调入口
- 唐山物桥任务列表
- 来源、阶段、进度、状态
- 继续处理进入详情

- 头部任务信息
- 流程进度
- 左侧阶段产物
- 右侧任务助手
- 税票/资料等待状态

Phase 3-C：工作台创建尽调任务并同步到智能尽调
- 工作台创建任务后，智能尽调首页能看到
- 工作台右侧只提供「稍后处理」
- 不点击「稍后处理」时，工作台完整流程继续可操作
- 点击「稍后处理」时不跳转，只提示去左侧菜单「智能尽调」

- 在任务台账点击「继续处理」后进入详情页
```

### 11.9.2 Phase 3-D：智能尽调与智能报告打通决策

产品决策：智能报告会创建一个「报告编写任务」，但不是在新建尽调时创建，而是在智能尽调进入「产物确认」后，由用户点击「编辑报告」或「同步到智能报告」触发。

原因：

```text
新建尽调时：工商、司法、税票、资料、证据、风险都尚未完成，报告任务过早创建会变成空任务。
产物确认时：报告草稿、证据链、风险结论和待确认项已经具备，适合创建报告编写任务。
```

采用方案 B：

```text
智能尽调内嵌 Lite 编辑，另有同步到智能报告
```

具体含义：

```text
智能尽调 · 产物确认
  ↓
点击「编辑报告」或「同步到智能报告」
  ↓
创建/复用智能报告编写任务
  ↓
智能尽调左侧切换为报告编辑 Lite
  ↓
右侧尽调助手提示：
已创建智能报告编写任务，可继续在当前页修改，也可进入智能报告深度编辑。
  ↓
按钮：
[在当前页编辑] [进入智能报告] [稍后处理]
```

Phase 3-D-1 先做：

```text
1. 产物确认阶段点击「编辑报告」/「同步到智能报告」创建或复用报告编写任务。
2. 智能尽调左侧显示报告编辑 Lite。
3. 智能报告首页最近报告列表能看到该任务。
4. 不强制从智能尽调跳转到智能报告。
5. 「进入智能报告」可以作为下一步按钮，但 Phase 3-D-1 不必须做深度跳转编辑。
```

Phase 3-D-2 继续做：

```text
1. 智能尽调 Lite 编辑态点击「进入智能报告」。
2. 页面跳转到智能报告模块，并携带 reportId。
3. 智能报告页面根据 reportId 自动打开对应报告任务的深度编辑态。
4. 智能报告编辑页显示同一份报告任务：唐山物桥商贸有限公司 / 尽职调查报告 / 来源智能尽调 / 草稿待编辑。
5. 用户在智能报告中进行完整编辑、版本管理、导出 PDF / Word。
```

D-2 推荐路径：

```text
智能尽调详情页
  ↓
产物确认
  ↓
编辑报告 / 同步到智能报告
  ↓
左侧进入报告编辑 Lite
  ↓
点击「进入智能报告」
  ↓
/smart-report?reportId=RPT-TS-WQ
  ↓
智能报告自动打开该任务 editor
```

这里的跳转是合理的，因为用户已经明确点击「进入智能报告」。和 Phase 3-C 不同，Phase 3-C 中工作台不应该直接把用户带入智能尽调详情；而 Phase 3-D-2 中，用户在报告 Lite 内主动选择进入智能报告深度编辑。

边界：

```text
不新建第二份报告任务。
不重新生成报告目录。
不改变智能尽调任务阶段。
不做交付包下载。
```

### 11.9.1 交付包下载节点的产品决策

新增产品决策：完整交付包下载不放在工作台，也不放在智能报告主页面，而是放在智能尽调的「产物确认」之后，形成第 8 个阶段。

原因：

```text
产物确认 = 看内容是否正确、是否需要修改
交付包下载 = 内容确认后，打包交付、下载归档
```

如果把所有 PDF、证据链、原始资料包都堆在产物确认里，会让产物确认节点过重。用户还没确认报告和授信建议，就看到大量下载项，流程感会变乱。

因此智能尽调最终阶段规划为：

```text
工商核验 → 司法查询 → 税票采集 → 资料补充 → 证据整合 → 风险诊断 → 产物确认 → 交付包下载
```

```text

├─ 尽职调查报告草稿
│  ├─ 查看报告
│  ├─ 编辑报告

│
├─ 待确认项

│  ├─ 税票异常说明待补充

│
└─ 操作
   ├─ 查看报告
   ├─ 编辑报告
```

### 11.10 智能尽调详情页交互形态：右侧必须是对话式任务助手

智能尽调详情页不能把右侧做成普通的「当前阶段 + 快捷操作 + 任务状态」静态卡片。这样虽然能处理任务，但不像 AI 产品，也无法模拟完整流程流转。

正确形态是：

```text
任务头部 + 流程条 + 左侧阶段产物 + 右侧对话式尽调助手
```

而不是：

```text
任务头部 + 流程条 + 左侧产物 + 右侧静态操作卡
```

右侧尽调助手要同时具备：

```text
- 消息流：AI 气泡、用户气泡、阶段推进提示
- 快捷动作：发送提醒、模拟授权、进入下一阶段、稍后继续
- 输入框：支持自然语言推进，例如“客户已经授权了”“继续下一步”“生成产物”
- 任务状态摘要：当前阶段、等待事项、同步状态、最近更新
```

## 12. 产物确认、报告预览与报告编辑的三态交互

### 12.1 产品判断

产物确认阶段不能把「尽职调查报告」作为一个小卡片简单展开。尽职调查报告是完整文档，内容长、章节多，需要足够阅读空间。

因此不采用“浏览器右侧 drawer”，也不采用“产物列表下方很深位置展开”。推荐使用左侧业务工作区整区切换：

```text
产物确认列表态
  ├─ 查看尽职调查报告 → 报告预览态
  ├─ 编辑尽职调查报告 → 报告编辑态
  └─ 查看其他产物 → 当前页轻量预览 / 小面板

报告预览态
  ├─ 进入编辑 → 报告编辑态
  ├─ 导出报告
  └─ 返回产物确认 → 产物确认列表态

报告编辑态
  ├─ 预览报告 → 报告预览态
  ├─ 保存草稿
  ├─ 导出最终报告
  └─ 返回产物确认
```

右侧 AI Copilot 始终保持存在，用于改写风险结论、补充税票说明、生成授信建议和导出最终报告。
