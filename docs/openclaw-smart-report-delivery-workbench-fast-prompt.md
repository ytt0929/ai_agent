# OpenClaw 快速实现提示词：智能报告改造成 AI 报告交付工作台

请修改 `D:\demo\ai-copilot` 项目中的“智能报告”功能。

本提示词是快速实现版，请严格按“定位、问题、目标、修改建议、验收标准、输出产物”执行。

## 1. 本次定位

你本次不是普通前端工程师，而是同时扮演：

- 资深 AI 产品经理
- 资深银行业务产品经理
- 资深前端工程师

智能报告的新定位是：

```text
AI 报告交付工作台
```

一句话定义：

```text
智能报告负责把模板、资料包、智能尽调产物和报告正文组织成可修改、可追溯、可导出的正式报告。
```

它不是企业分析工具，也不是企业问数工具。

模块边界：

```text
企业探查：数据到洞察，例如问数据、算指标、找异常、解释评分
智能尽调：资料到尽调结论，例如核验证据、形成待确认结论
智能报告：资料到报告，报告到交付，例如模板、资料包、正文修改、批量导出
```

智能报告可以上传资料、识别资料、生成报告、提示缺资料，但不替代完整尽调核验。

## 2. 当前问题

当前智能报告存在以下问题：

1. 产品方向偏 SaaS 报告管理页
   - 页面容易变成统计卡、模板卡、报告列表。
   - AI 没有围绕报告交付任务发挥作用。

2. 模块边界不清
   - 问数据、算指标、找异常、解释评分不应该放在智能报告。
   - 这些能力应属于【企业探查】。

3. 当前代码存在潜在实现风险
   - 请先阅读现有 `SmartReportPage.vue` 和 `mockSmartReport.js`，判断当前结构是否支撑新定位。
   - 保持项目现有文件风格和编码习惯。
   - 如发现实际页面显示、源码或 `npm run build` 存在问题，再做必要修复。

4. mock 数据结构不支撑新定位
   - 需要补充模板、资料包、章节资料关联、待确认事项、导出包等数据。

5. 兼容风险
   - `src/stores/smartReport.js` 可能仍引用 `mockSmartReport.js` 里的旧导出：
     - `reportTemplates`
     - `dataSources`
     - `reportHistory`
     - `getReportContent`
   - 重写 `mockSmartReport.js` 时必须保留这些兼容导出，避免构建失败。

## 3. 本次目标

把 `/smart-report` 改造成一个银行客户经理使用的 AI 报告交付工作台。

核心能力：

1. AI 任务入口
   - 用户可以直接让 AI 处理报告交付任务。
   - 例如：按新模板生成、上传资料生成、改写章节、查看资料包、批量导出。

2. 模板管理
   - 展示报告模板库。
   - 支持上传新模板的 UI 反馈。
   - 展示模板版本、章节数、资料要求。

3. 资料包管理
   - 展示客户资料包、尽调证据包、补充附件。
   - 支持查看资料详情、修改资料摘要、上传补充资料。

4. 报告生成
   - 支持从智能尽调产物生成报告。
   - 支持上传资料附件生成报告。
   - 支持按新模板重新生成报告。

5. 报告正文修改
   - 支持章节级正文编辑。
   - 支持 AI 快速改写文字表述。
   - 支持待确认内容快速修改。

6. 章节资料追溯
   - 每个章节能看到关联资料包。
   - 能看到资料来源、状态、识别摘要。
   - 能修改资料包内容。

7. 交付导出
   - 支持导出报告。
   - 支持报告 + 资料包批量导出。

```text

```

## 3.2 真实产品交互要求

不要只做静态卡片。每个核心动作必须有明确状态变化或反馈。

必须形成以下交互闭环：

### 3.2.1 上传资料附件生成报告

流程：

```text
首页点击上传资料附件生成报告
-> 上传面板
-> AI 识别资料
-> 显示已识别资料和缺失资料
-> 点击生成报告草稿
-> 生成态
-> 编辑页
```

### 3.2.2 修改待确认内容

流程：

```text
首页点击修改待确认内容
-> 编辑页
-> 定位待确认章节或显示待确认事项
-> AI 改写当前章节
-> 用户保存
-> 状态变为已确认或待确认数减少
```

### 3.2.3 查看章节资料包

流程：

```text
编辑页点击章节
-> 右侧显示当前章节资料列表
-> 查看资料详情
-> 修改资料摘要
-> 标记资料已修改
-> 可根据资料包重新生成本节
```

### 3.2.4 按新模板重新生成

流程：

```text
点击按新模板重新生成
-> 选择或展示新模板
-> 展示章节映射提示
-> 生成态
-> 更新报告章节
```

### 3.2.5 批量导出

流程：

```text
点击批量导出报告和附件
-> 展示导出内容选择
-> 勾选报告正文、附件清单、资料包、证据目录
-> 生成导出任务
-> message 反馈
```

- `/smart-report` 默认显示“智能报告工作台”
- 首页第一屏最大视觉元素是 AI 任务输入框
- 首页快捷任务围绕报告交付：生成、上传、重排、修改、资料包、导出
- 首页有待处理报告、报告模板、资料包三个工作区
- 统计卡存在但不抢主视觉
- 待处理报告每条都有 AI 提示和交付状态

### 7.3 上传资料生成报告验收

- 点击“上传资料附件生成报告”后出现上传面板
- 上传面板展示模板选择、资料上传、AI 识别结果、缺失资料
- 点击“生成报告草稿”进入生成态
- 生成完成进入编辑页

### 7.4 编辑页验收

- 编辑页是三栏布局：目录、正文、右侧资料包 + AI 助手
- 左侧章节可切换
- 中间正文可局部编辑并保存
- 当前章节能看到资料依据、待确认提示、缺失资料提示
- 右侧能看到当前章节关联资料
- 右侧能查看资料详情、修改资料摘要、上传补充资料

### 7.5 AI 报告交付助手验收

- 点击“改写当前章节”有 mock 回复
- 点击“改成审批口吻”有 mock 回复
- 点击“根据资料包重新生成本节”有 mock 回复并说明引用资料
- 点击“检查本节缺失资料”有 mock 回复
- 点击“查看本节引用资料”有 mock 回复
- 点击“按新模板重新生成”有 mock 回复
- 点击“批量导出报告和资料包”有 message 或 mock 回复

### 7.6 提交与导出验收

- 有待确认事项时，提交会 warning 阻断
- 有缺失资料时，提交会 warning 阻断
- 全部确认且资料完整后，提交显示 success
- 导出报告有 message 反馈
- 导出报告和资料包有 message 反馈

### 7.7 交互闭环验收

- 上传资料附件生成报告流程可走通：上传面板 -> 识别结果 -> 缺失资料 -> 生成态 -> 编辑页
- 修改待确认内容流程可走通：进入编辑页 -> 定位待确认项 -> AI 改写 -> 保存 -> 状态变化
- 查看章节资料包流程可走通：切换章节 -> 查看资料详情 -> 修改资料摘要 -> 标记已修改
- 按新模板重新生成流程可走通：触发动作 -> 展示章节映射 -> 生成态 -> 回到编辑页
- 批量导出流程可走通：选择导出内容 -> 生成导出任务 -> message 反馈
- 所有核心按钮都不能是无反馈的静态按钮
- 所有状态变化都要在 UI 上可见，至少通过标签、数量变化、message 或列表内容变化体现
