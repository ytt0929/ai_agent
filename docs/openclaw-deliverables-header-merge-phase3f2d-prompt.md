# OpenClaw Prompt - Phase 3-F-2D 产物确认页头部合并优化

请严格按本提示词修改。目标是只优化【产物确认】页面当前节点的展示层：压缩重复头部、弱化厚重卡片头，让「核心产物」和「确认生成交付包」成为页面主线。不要抽公共组件，不要一次性改其他 7 个节点。

## 修改范围

只允许修改：

- `src/components/workbench/artifacts/DeliverablesArtifact.vue`

禁止修改：

- `src/stores/workbenchAssistant.js`

## 重要边界

1. 不要抽公共 Header 组件。
2. 不要改工作台或智能尽调详情页的整体布局。
3. 不要改 store 状态机、mock 数据、流程推进逻辑。
4. 不要做编码转换，不要处理乱码。浏览器页面不是乱码。
5. 不要引入新的 UI 库，只用 Element Plus 和项目现有 token。
6. 不要删除报告预览能力。

## 当前问题

产物确认页现在的问题是：

1. 顶部摘要条、核心产物卡片 header、报告模板与资料包卡片连续出现，视觉上像多个表格头；
2. 「产物确认」节点摘要和外层任务头里的状态、完整度信息有重复；
3. 页面真正重要的内容是核心产物清单、待确认项、生成交付包按钮，但被上方头部挤压；
4. 主按钮容易贴近容器边缘或在窄宽度下显得拥挤。

## 具体实现要求

### 1. 顶部摘要必须轻量

当前 `dl-summary-bar` 可以保留，但要继续弱化，不要像一个厚表格头。

要求：

- 高度控制在约 64-84px；
- 背景轻，边框轻；
- 标题、说明、tag 在同一信息区；
- 不要大面积色块；
- 不要重复展示企业名、评分、风险等级，这些外层任务头已经有；
- 只表达当前节点：产物确认、已生成、待确认数量、资料完整度、下一步是生成交付包。

推荐结构：

```text
产物确认  [已生成] [待确认 2 项] [资料完整度 86%]
尽调报告草稿、阶段报告、证据链和资料包已生成，请确认后生成交付包。
```

### 2. 核心产物表格不要显得头很重

`el-card` 可以保留，但 header 要轻。

要求：

- card header 高度不要太高；
- 标题只保留 `核心产物`；
- 不要再放过多状态 tag；
- 表格用 `el-table size="small"`；
- 表头字号和颜色保持项目默认或 token，不要加粗过度；
- 操作列按钮继续可用。

### 3. 报告模板与资料包区域要轻量

可以保留 `el-descriptions`，但不要视觉上比核心产物更重。

要求：

- `column=1` 可保留；
- header 简洁；
- 文案保持：
  - 报告模板：`尽职调查报告`
  - 报告底稿：`尽职调查报告`
  - 资料包：工商资料 / 司法查询 / 税票数据 / 上传资料
- 不要增加复杂图标或大块背景。

### 4. 待确认项要紧凑

待确认项可以继续用 `el-alert`，但要紧凑：

- 每项高度不要过大；
- 可以只显示事项名称，不要长说明挤占空间；
- 保留 warning 语义。

### 5. 操作区必须不溢出

底部操作区必须：

```css
display: flex;
flex-wrap: wrap;
justify-content: flex-end;
gap: var(--space-sm, 8px);
```

主按钮 `确认产物并生成交付包` 要明显，但不能超出背景。

如果宽度不足，按钮允许换行，不允许溢出到容器外。

按钮顺序保持：

1. 确认产物并生成交付包（primary）
2. 同步到智能报告
3. 导出报告
4. 加入监控

### 6. 报告预览必须保留

点击「查看」尽职调查报告后，仍然进入当前组件内部的报告预览状态。

要求：

- 不使用 drawer 覆盖右侧 AI；
- 不跳路由；
- 预览仍包含报告目录、正文、证据链、待确认项；
- 「返回产物确认」「进入编辑」「导出报告」继续可用。

### 7. 样式必须使用 token

所有新增或调整样式优先使用：

- `var(--text-primary)`
- `var(--text-secondary)`
- `var(--text-tertiary)`
- `var(--surface-card)`
- `var(--surface-soft)`
- `var(--border-color-divider)`
- `var(--space-xs)`
- `var(--space-sm)`
- `var(--space-md)`
- `var(--radius-md)`

不要新增大量硬编码颜色、阴影、大圆角。
