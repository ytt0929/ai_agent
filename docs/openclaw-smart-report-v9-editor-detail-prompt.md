# OpenClaw 提示词：智能报告详情页体验优化

你是资深前端工程师、资深 UX/UI 工程师。请只修改“智能报告”的单户授信调查报告详情页体验，本轮不要改首页、不要改任务识别页、不要改智能尽调、不要改路由和侧边栏。

## 当前项目情况

- 技术栈：Vue 3 + Vite + Element Plus。
- 当前主要文件：`src/pages/SmartReportPage.vue`。
- 当前详情页是 `view === 'editor'`。
- 当前详情页已有三栏：
  - 左侧：报告目录
  - 中间：报告正文
  - 右侧：AI 写作助手
- 当前证据链只在正文底部统一展示，体验不够贴近“每章确认”。
- 当前右侧 AI 面板有收起状态，打开报告后默认是收起的。
- 当前详情页底部还有明显留白，三栏没有真正撑满页面。

## 本轮只允许修改

- `src/pages/SmartReportPage.vue`

不要修改：

- `src/data/mockSmartReport.js`
- 智能尽调相关文件
- 企业探查相关文件
- 路由
- 侧边栏
- 全局样式文件
- 其他页面

## 本轮目标

把“单户授信调查报告详情页”调整成更像真实银行客户经理的 AI 报告编辑工作台：

1. 每个报告章节下面都能看到可展开的章节证据链。
2. 三栏内容要撑满当前页面高度，底部不要出现大面积留白。
3. 右侧 AI 写作助手默认展开。
4. 右侧 AI 面板要有明确的修改引导。
5. 每个章节都要模拟一条 AI 修改建议，用户切换章节时右侧 AI 面板能体现当前章节建议。

## 具体修改要求

### 1. 报告详情页默认展开 AI 面板

当前 `assistantCollapsed` 默认是 `true`，并且 `openReport()` 里会设置为收起。

请修改为：

- 打开报告详情页时，AI 写作助手默认展开。
- `assistantCollapsed` 初始值改成 `false`。
- `openReport(task)` 中不要把 AI 面板设置成收起。
- 打开报告后，AI 面板第一条消息应提示：
  - 当前报告名称
  - 当前章节
  - 当前章节状态
  - 当前章节关联证据数量
  - 当前章节 AI 建议

示例文案：

“已打开《明达精工有限公司 - 单户授信调查报告》。当前章节为《履职声明与基本信息》，本节已生成，关联证据 1 条。AI 建议：本节可以补充调查依据和资料来源说明，使履职声明更符合授信调查报告口径。”

### 2. 每个章节正文下方增加可展开证据链

当前证据链是固定展示在正文底部的 `章节证据链` 区块。

请改成更贴近“每章证据确认”的交互：

- 在每个章节正文内容后方展示一个可展开区域。
- 推荐使用 Element Plus 的 `el-collapse` / `el-collapse-item`。
- 标题建议为：

`本章证据链（已关联 X 份资料）`

- 默认可以展开当前章节证据链，也可以默认展开第一项，但不能完全隐藏到用户找不到。
- 展开后展示当前章节关联资料：
  - 资料名称
  - 状态：已关联 / 缺失 / 待补
  - 来源
  - 摘要
  - 操作：详情 / 修改摘要 / 补充 / 转入尽调补充
- 如果当前章节没有资料，显示空状态：
  - “本章暂无关联资料，建议补充资料或转入尽调补充。”

注意：

- 证据链应该属于当前章节内容的一部分。
- 不要把证据链放到右侧 AI 面板。
- 左侧目录可以继续保留“章节证据链”入口，但重点是每章正文下面就能展开证据链。

### 3. 每个章节模拟 AI 修改建议

请给每个章节生成或计算一个模拟 AI 建议，不需要改 mock 数据文件，可以在 `SmartReportPage.vue` 内用函数根据章节状态生成。

建议新增函数，例如：

```js
function getSectionAiSuggestion(section) {
  if (!section) return ''
  if (section.materialStatus === '资料不足' || section.materialStatus === '部分缺失') {
    return '本节资料不完整，建议先补充关键资料，再生成正式表述。'
  }
  if (section.status === '待确认') {
    return '本节存在待确认内容，建议重点核对事实依据、金额、时间和结论表述。'
  }
  return '本节结构基本完整，建议优化表述口径，补充资料来源和调查判断。'
}
```

右侧 AI 面板需要展示当前章节 AI 建议：

- 当前章节名称
- 当前章节状态
- 关联证据数量
- AI 建议
- 推荐操作按钮：
  - 改写当前章节
  - 检查证据链
  - 生成缺失说明
  - 标记本节确认
  - 转入尽调补充

这些按钮仍然放在 AI 消息气泡下面，不要放成顶部大工具栏。

切换章节时，右侧 AI 面板的第一条提示内容要跟随当前章节变化。

### 4. 右侧 AI 面板交互优化

当前右侧 AI 面板底部区域留白较多，输入框位置偏低，内容不够突出。

请调整为：

- 面板高度撑满详情页内容区。
- Header 轻量化，只保留：
  - `AI 写作助手`
  - `收起`
- 中间消息区自适应撑满。
- 输入框固定在面板底部。
- 消息区要优先展示：
  - 当前章节 AI 建议
  - 推荐修改动作
  - 用户后续对话
- 不要让输入框悬浮在一大片空白上方。
- 不要让右侧面板产生页面级留白。

### 5. 修复详情页底部大面积留白

当前详情页底部有明显空白，说明高度计算不正确。

请检查并调整以下样式：

- `.sr-page`
- `.sr-editor`
- `.sr-editor__header`
- `.sr-editor__body`
- `.sr-editor__toc`
- `.sr-editor__content`
- `.sr-editor__sidebar`
- `.ai-assistant-panel`
- `.ai-assistant-panel__body`
- `.sr-ai-msgs`

目标：

- 详情页整体填满当前视口。
- Header 固定在详情页顶部。
- Body 占满剩余高度。
- 左侧目录、中间正文、右侧 AI 面板都在 body 内部独立滚动。
- 页面底部不再出现大块空白。
- 不要因为强行设置过小高度导致正文内容被遮挡。

建议方向：

- `.sr-editor` 使用 `height: calc(100vh - 合理顶部间距)`。
- `.sr-editor__body` 使用 `flex: 1; min-height: 0; overflow: hidden;`。
- 三栏容器内部各自 `overflow-y: auto`。
- 避免 `.sr-editor__body` 再写一个和 `.sr-editor` 冲突的 `height: calc(...)`。
- 不要让全局页面继续额外滚动出底部空白。

### 6. 左侧目录优化

左侧目录现在章节较多，建议保持紧凑，但要更清晰：

- 当前章节高亮要明显。
- 状态标签不要挤压标题。
- 目录可以独立滚动到底。
- 不要因为目录内容不够高导致下面大面积空白影响三栏整体。

## 实现建议

请按最小改动实施，不要重写整个文件：

1. 先改 `assistantCollapsed` 默认展开和 `openReport()` 逻辑。
2. 再把正文底部证据链改成当前章节正文下方的 `el-collapse`。
3. 再新增当前章节 AI 建议函数，并让 AI 面板第一条提示随章节切换。
4. 最后修三栏高度和底部留白。

如果需要新增少量 `ref` 或 `computed`，可以直接写在 `SmartReportPage.vue` 里。不要新增组件文件。
