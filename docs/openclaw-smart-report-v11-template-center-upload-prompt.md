# OpenClaw 提示词：智能报告模板中心与上传模板页优化

你是资深前端工程师、资深 UX/UI 工程师。请优化智能报告中的“报告模板中心”和“上传新版模板”二级页面样式与交互。本轮重点是把模板中心做成截图中的业务表格型页面，并补齐上传模板页面。不要改智能尽调、企业探查、路由、侧边栏和全局样式。

## 当前项目情况

- 技术栈：Vue 3 + Vite + Element Plus。
- 当前主要文件：`src/pages/SmartReportPage.vue`。
- 当前已有 `view === 'templateCenter'`。
- 当前模板中心已经有模板列表、查看章节规则 drawer、上传模板 dialog。
- 但当前页面仍偏卡片式，不够像截图中的“表格型模板维护中心”。
- 上传新版模板目前只是弹窗模拟，应该升级成一个独立上传页面/步骤页。

## 本轮只允许修改

- `src/pages/SmartReportPage.vue`

不要修改：

- `src/data/mockSmartReport.js`
- 智能尽调相关文件
- 企业探查相关文件
- 路由
- 侧边栏

- 其他页面

## 样式一致性要求

本轮页面样式必须和当前项目整体保持一致：

- 使用 Element Plus 组件为主。
- 保持当前系统的浅灰页面背景、白色内容区、细边框、蓝色主按钮、轻量状态标签。
- 不要新增全局 CSS，不要改 `tokens.css`、`global.css`、`style.css`。
- 不要使用营销页式大卡、渐变、插画、装饰图形。
- 不要做过重阴影。
- 表格、按钮、标签、抽屉、上传区都要符合当前后台业务系统风格。
- 页面布局要紧凑、清晰，像银行内部配置工作台。
- 内容区宽度要更充分利用页面空间，接近用户截图中红框范围。

## 产品目标

报告模板中心的定位是：

- 维护不同银行、分行、报告类型的模板
- 查看模板章节规则
- 查看模板必需资料
- 查看 AI 生成提示词和禁用词规则
- 上传新版模板
- 让 AI 解析模板并生成章节规则、资料映射规则

这个页面不是营销页，不是 AI 聊天页，而是银行客户经理/管理员使用的模板配置工作台。

## 五、交互规则
