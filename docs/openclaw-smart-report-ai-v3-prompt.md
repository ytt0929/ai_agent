# OpenClaw Prompt V3: 智能报告升级为多报告类型 AI Copilot

请修改 `D:\demo\ai-copilot` 项目中的“智能报告”功能。

本次目标不是做传统 SaaS 报告管理页，也不是只做“单户尽调报告编辑器”，而是做一个 **面向银行客户经理的 AI 报告分析与生成工作台**。

核心定位：

```text
AI 通过对话操作企业数据和报告内容。
```

智能报告需要同时支持：

- 企业全景报告：工商 + 税票 + 经营数据罗列，支持问数据、算指标、找异常、调整报告。
- 单户尽调报告：尽调证据 + 风险诊断 + 授信方案，支持证据审查、结论改写、提交前检查。
- 企业诊断风险报告：风险评分 + 异常解释 + 监测建议，支持风险追问和诊断解读。

## 0. OpenClaw 本次角色定位

你不是普通前端工程师。本次请同时扮演：

### 1. 资深 AI 产品经理

- 把智能报告从“报告管理 SaaS”改造成“AI Copilot 型报告工作台”。
- 首页第一视觉必须体现：用户可以直接让 AI 处理报告、问数据、算指标、审查证据、修改正文。
- 不要把产品做成指标卡 + 模板卡 + 列表的传统后台。
- AI 要主动给出下一步建议，而不是只等用户点按钮。

### 2. 资深银行业务产品经理

- 理解不同报告的业务目标不同：
  - 企业全景报告：快速理解企业经营、工商变化、税票趋势和经营指标。
  - 单户尽调报告：把尽调证据变成可提交的授信调查报告，关注证据链、风险依据、审批口径。
  - 企业诊断风险报告：解释风险评分、异常信号和监测建议。
- 所有 AI 建议必须围绕银行客户经理真实工作：看企业、问数据、算指标、查风险、补证据、改报告。

### 3. 资深前端工程师

## 6. 生成态

当用户触发生成或分析时，进入生成态。

生成步骤根据报告类型变化。

### 企业全景报告生成步骤

1. 读取工商数据
2. 读取税票数据
3. 计算经营指标
4. 识别异常月份
5. 生成经营结论

### 单户尽调报告生成步骤

1. 读取尽调证据包
2. 匹配授信调查报告模板
3. 生成正文和表格
4. 检查缺失证据
5. 生成提交前审查建议

### 诊断报告生成步骤

1. 读取风险评分
2. 汇总异常信号
3. 解释风险原因
4. 生成监测建议
5. 形成诊断摘要

生成完成后进入对应报告编辑页。
